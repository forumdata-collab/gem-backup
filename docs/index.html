Gem Backup

Open Source · MIT License

Google is sunsetting Gems (custom Gemini instructions) in October 2026. Paste a public Google Drive folder URL and Gem Backup packages every Gem's name, description and full system prompt into a clean .xlsx — plus a .zip of any attachments. Files auto-delete after 30 minutes.

Open the Tool Source on GitHub

Why this exists

Before October 2026 — or any time you tidy your Gemini library — you should own your Gems as plain, portable data. Downloading them manually one by one is tedious; this service does it in one click with no account, no OAuth, no AI involved.

How it works

StepWhat happens
1. ListPublic folder parsed via Google's embeddedfolderview endpoint (no API key)
2. DownloadEach Gem + attachment streamed via the public uc?export=download endpoint
3. ParseGem files are protobuf — name, description and instructions extracted with a small decoder
4. PackageExcel with 32,767-char-safe cell chunking + attachment zip
5. HandoutBoth files downloadable for 30 minutes, then deleted from the server

Requirements

Just one: the folder must be shared as Anyone with the link (Viewer). Everything else is handled automatically.
